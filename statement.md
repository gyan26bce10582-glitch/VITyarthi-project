Hostel Attendance System

In a hostel it can be hard to know which students are here and which students are not especially when there are a lot of students.

For this project I made a Python program to handle student attendance. The user can look at the attendance list update a students attendance and add a student.

I made this project to use the Python skills I learned in my year and apply them to a simple real-life problem.

This project is mostly about hostel attendance management.

The program can do the following:

- Show the attendance of all students who are registered.

- Change a students status to Present or Absent.

- Add a student.

- Check if a student is already registered.

- Check if a student exists before changing their attendance.

- Take user input through a simple menu.

Now the attendance records are kept only while the program is active. If the program is closed the changes are gone.

This project can be used by:

- Hostel students

- Hostel representatives

- Hostel wardens

- Students who want to manage an attendance list

It is mainly a college project and is not meant to be a full hostel management system.

The user can choose the view option to see all the students and their current attendance status.

The user can choose a student. Change their status to either Present or Absent.

A new student can be added to the attendance list. When a student is added their status is set to Present by default.

The program checks if the student is already in the records. This helps avoid adding the student more than once.

The program has a menu where the user can choose what they want to do by entering a number.

The project uses:

- Python 3

- Python dictionaries

- Functions

- if-else conditions

- for loops

- while loops

- User input

- Basic string methods

No extra Python libraries are needed for this project.

Since this is a first-year project it has some limits.

- The attendance is not saved for good.

- There is no database.

- There is no login system.

- Attendance is not stored by date.

- The program does not calculate attendance percentage.
